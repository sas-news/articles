# EV3 OSとは
EV3には様々なOSが存在します。
デフォルトOSを除き、世の中に存在するサードパーティ製のEV3 OSはSDカードにOSデータを入れ、起動するものです。

サードパーティ製のEV3 OSを利用する理由は主にこんな感じです。
1. 慣れた言語でコーディングできる。
2. 動作によってはデフォルトOSより速い。
3. デフォルトOSにはない機能が存在する。
4. ~~(EV3の大会などで)つよつよに見える。ドヤれる。~~

じゃあ実際にどのOSがいいのかということで、いろいろなOSを実際に使ってみました。
| OS | 言語 | 特徴 |
| -- | ---- | ---- |
| [デフォルト](https://afrel.co.jp/product/ev3-introduction/) | ブロック | 速度が速く、プログラムが楽 |
| [ev3dev](https://www.ev3dev.org/) | Python, Java, Go, C, etc | 言語数が豊富だが起動が遅い |
| [EV3RT](https://dev.toppers.jp/trac_user/ev3pf/wiki/WhatsEV3RT) | C | コンパイル言語だから起動、動作が速い |
| [MonoBrick](http://www.monobrick.dk) | C#, F#, IronPython | Monoをベースに.NET  Frameworkが動く |
| [leJOS](https://lejos.sourceforge.io) | Java | 機能が充実している |

# なぜMonoBrickなのか
## 利点
### 起動時間
まず起動時間が速く、1分で起動します。いつもデフォルトOSを使っている人にとっては遅いでしょうが、ev3devが3分ほどかかるのでいつもev3devを使っている人にはとても速く感じます。
1分というのはサードパーティ製のEV3 OSの中では、平均より少し早いぐらいでしょうか。
でもev3devユーザーが多いので利点とします。
### メニュー
MonoBrickではプログラムの中からメニューを呼び出すことができます。
これにより、プログラムのランチャーなどが作りやすくなります。また、同時にキーボードも表示できるます。
### フォント
他のEV3 OSではフォントは最低限のデザインでしかありませんが、MonoBrickのフォントは大きく読みやすくなっています。
## 欠点
### 開発終了
MonoBrickは既に更新されていません。MonoBrickの最新バージョンは2015年です。これは各OSの最終更新がev3devが2020、EV3RTが2021なのをみると、非常に古いです。更新されていないと問題も発生するものなので、嫌な人は他のOSを使いましょう。
### Bluetooth
MonoBrickでは基本的にBluetoothが使えません。詳しく説明すると2016年にEV3のBluetoothの規格が変更され、MonoBrickでは動かなくなりました。
### 機能
メニューがこれでもかというほど最小限です。できることがほとんどありません。
メニューの操作性が悪いです。一番上から一番下にワープされません。いちいち下ボタンを連打する必要があります。
