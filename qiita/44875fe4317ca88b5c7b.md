SPIKEプライムのプログラムをVSCodeで書ければ便利だと思いますよね。Pybricksを使うのが定石ですが、公式のファームウェアを使いたい場合は、以下のように行います。

:::note warn
SPIKEをVSCodeで使ったとて、複数のファイルを扱えないという致命的な問題は解決されません。複数ファイルを使うならおとなしくPybricksを使いましょう。
:::

## ダウングレード
バージョン3ではまだできないそうなので、バージョンを2に下げます。
通称SPIKE Legacyです。

https://afrel.co.jp/product/spike/technology-spike/basic/software-basic/54122/

アフレルが手順を公開しているので、これに従えば簡単にできます。

## 拡張機能
https://marketplace.visualstudio.com/items?itemName=PeterStaev.lego-spikeprime-mindstorms-vscode

すごくありがたい拡張機能が公開されているので、こちらを使います。Marketplaceに公開されているのでVSCodeで検索すれば見つかります。

## 初期設定
フォルダーを開いたら中に適当なPythonファイルを作ってもらって、右上の「LEGO Hub: Add File Header」を選びます。「Python (standard)」と「Python (advanced)」があります。standardは通常のSPIKE2のPythonそのままです。advancedは一度Scratchに変換することで、非同期処理を強くしているみたいです。

advancedは情報が少なくて調べ切れていないので、今回はstandardを使います。すみません。

そのまま進めると、以下のようなコメントがPythonファイルに追加されます。
```py
# LEGO type:standard slot:0 autostart
```
このボタンで行われるのはこのコメントの追加のみなので、使う必要がなければコピペかコメントを自分で書いてもいいですね。

## 実行
左下のメニューから「LEGO Hub: Disconnected」を押すと接続可能なデバイスのリストが出てくるので、繋げたいHubを選んでください。もう一度押すと接続が切断されます。

:::note warn
SPIKEのアプリを起動しているとそちらが優先されるため、VSCodeで接続できません。
:::

右上のメニューが増えるので、それぞれ解説します。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/2883745/684a8bba-f3e4-9ca0-b868-7b169df7d9bd.png)
- 1番左の「Start Program」はSPIKEにすでにアップロードされたプログラムを遠隔で実行するボタンです。
- 2番目の「Terminate Runnning Program」は現在実行中のプログラムを強制終了します。
- 3番目の「Upload Program」は名前の通り、現在のプログラムをHubにアップロードします。上の設定で「autostart」をオンにしていれば実行も同時になされます。
- 4番目の「Show Log Terminal」はVSCode上でターミナルを表示してHubのログを確認できます。
- 1番右のボタンは先ほど説明したとおりです。

## 補完
プログラムは正常に動きますが、VSCode側では「インポート"spike"を解決できませんでした」といったインポートエラーが発生します。

補完をするにはこちらのGitHubのリポジトリを使うといいでしょう。クラスや関数の構成を疑似的に再現することで、VSCodeの補完が効くようになります。先ほど書いたようにSPIKEでは複数ファイルをアップロードすることができないので、競合によるエラーは発生しません。

https://github.com/dctian/lego-spike-prime-py

こちらをそのままzipとしてダウンロードし、VSCodeで開くだけで完了です。簡単に補完ができます。
main.pyの中身を消して、作業するのがいいでしょう。`hub`と`spike`フォルダは補完用なので消さないように注意してください。
