PCとMonoBrickを接続することでプログラムの実行ができるようになります。
接続する方法は主に3つあります。どれも利点欠点があるので、自分の環境に適した方法を選んでください。私のお勧めはUSBです。
# PCと接続
- [USBで接続](#usbで接続)
- [Bluetoothで接続](#bluetoothで接続)
- [Wifiで接続](#wifiで接続)
## USBで接続
### ダウンロード
![MicrosoftUSBDriver](https://storage.googleapis.com/zenn-user-upload/c557fe1c4145-20230913.png)
[MicrosoftUpdateカタログ](https://www.catalog.update.microsoft.com/Search.aspx?q=USB%20RNDIS%20Gadget)
Windows10,11でUSBで接続するにはUSBドライバーが必要になります。
上のサイトに入って「Acer Incorporated. - Other hardware - USB Ethernet/RNDIS Gadget」というファイルを探してください。2つ見つかると思うので「Windows 7, Windows 8, Windows 8.1 and later drivers」の方をクリックします。
新しいウィンドウが表示されるので`20342322_4b9970e3174b23b5cb2371af0837f939a71271ea.cab`を押してダウンロードして「7-zip」で展開してください。
### インストール

「デバイスマネージャー」の一覧から「ポート(COMとLPT)」を見つけ、中のUSBデバイスを右クリックして「ドライバーの更新」を選んでください。。複数あってどれがEV3かわからない場合は、USBを抜き差しして表示非表示が変わるものがEV3です。
![USBdriver](https://storage.googleapis.com/zenn-user-upload/813c77b6e9e1-20230914.png)
「コンピューターを参照してドライバーを検索」から、先ほど展開したフォルダを選択します。「ドライバーが正常に更新されました」と表示されたら完了です。

## Bluetoothで接続
:::note warn
2016年以前に製造された旧バージョンEV3でのみBluetooth接続ができます。具体的にはこの時期にEV3のBluetoothのチップが変更されました。確認方法はEV3の箱についているシールのバージョンが「46」が旧バージョン、「121」が新バージョンです。最新のEV3のバージョンが何なのかは確認できませんでしたが、バージョンが「46」より大きい場合接続できない可能性が高いです。
:::
:::note
旧型のEV3がないので、Bluetooth接続の解説はleJOSのものです。公式ドキュメントより、この方法でできるらしいですが検証できていません。
:::
![Bluetooth](https://storage.googleapis.com/zenn-user-upload/3c720576344f-20230917.png)
Windowsの設定の「Bluetoothとデバイス」を選択し、「デバイスの追加」を押します。

### 接続を完了する
上のどちらかの方法でPCとEV3が接続できたら、コントロールパネルを開きます。

「デバイスとプリンターの表示」から「デバイスとプリンター」を表示させます。
![デバイスとプリンター](https://storage.googleapis.com/zenn-user-upload/47e5fadbbacd-20230916.png)

今回PCに接続したEV3の名前が一番下の「未指定」のグループにあると思うので、右クリックメニューの「接続方法」の中の「アクセスポイント」に設定します。

このコントロールパネルを開く以降の作業はEV3を再起動するたびに実施する必要があります。
## Wifiで接続
Wifi経由でEV3に接続する場合は、Wifiドングルが必要です。既にWifiドングルを持っている人以外はこの方法を使う必要はないと思います。
EV3本体にWifiドングルを差し込んでからMonoBrickを起動します。付いたままの人は一度再起動してください。
メニューから「WiFi Connection」を選び、今回接続したいWifiを選択します。「SSID」にWifiの名前を、「Password」にWifiのパスワードを入力して一番下の「Connect」にチェックを入れてください。「Encryption」は基本的にWPA/2だと思うので変更しなくて大丈夫です。接続に失敗したのみ変更してみてください。接続には少し時間がかかります。
「Main menu」に戻り「Information」を押すと一番下に「IP」という場所に「192.~.~.~」といったIPアドレスが表示されていれば接続完了です。

# 接続確認
上の方法でPC接続が完了したら、PowerShellを開いて以下のコマンドで確認しておきます。
```
ping 10.0.1.1
```
Wifi接続の場合はIPアドレスを入れてください。
![powershell](https://storage.googleapis.com/zenn-user-upload/b562a691734b-20230916.png)
このような表示が出てくれば、接続成功です。
「要求がタイムアウトしました。」と表示されたら接続できていないので、今一度手順を確認してみてください。
