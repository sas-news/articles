# OSイメージの取得
![MonoBrick](https://storage.googleapis.com/zenn-user-upload/866314e4558d-20230925.png)
[MonoBrick EV3 Firmware](http://www.monobrick.dk/software/ev3firmware/)
「4GB Image」をダウンロードしてください。「512MB」「2GB」「4GB」の違いはSDカードに作る作業領域が違います。ただ、4GBも作業領域を使用することはめったにないと思うのでどれを選んでも構いません。4GBのMicroSDを使用している方は一つ小さいものにしたほうがいいです。

# フォーマット
PCにMicroSDカードを刺してください。
エクスプローラーを開くと左下に新しいSDカードドライブが表示されているので、右クリックして「フォーマット」を選択してください。
![Format](https://storage.googleapis.com/zenn-user-upload/c95233057c9e-20230925.png)
このような画面が出てきます。「ボリュームラベル」を「MonoBrick」などわかりやすい名前に変えておくと、今後MicroSDをPCに差し込んだ時にわかりやすいです。
他の設定は特にいじる必要はないので、「クイックフォーマット」にチェックがついていることを確認して「開始」を押してください。
警告が出てくるので、しっかりとドライブがあっていることを確認して「はい」を押します。
違うドライブをフォーマットしてしまうと、ドライブのデータがすべて消えてしまうのでよく確認してください。
# MicroSDに焼く
![balenaEtcher](https://storage.googleapis.com/zenn-user-upload/6dd926e26334-20230925.png)
先ほどインストールしたbalenaEtcherを起動して、「Flash from file」を押して今ダウンロードしたOSイメージを選択してください。真ん中の「Select target」を押して今回MonoBrickを焼くMicroSDを指定してください。このときフォーマット時に設定した名前は表示されないので注意してください。設定できたら「Flash!」を押して焼いてください。画面に「Flash Completed」と表示されたら、MicroSDをPCから抜いていいです。
# いざ起動
EV3のMicroSDスロットに今OSを焼いたMicroSDを入れてください。
起動方法は通常のEV3 OSと同じです。最初は通常の画面が表示されますがいずれ下のような画面になれば正しくOSが焼けています。
![MonoBrick](https://storage.googleapis.com/zenn-user-upload/e683508c0148-20230925.jpg)
1分ほど待って「Main menu」と表示されたメニューらしき画面になったら成功です。
