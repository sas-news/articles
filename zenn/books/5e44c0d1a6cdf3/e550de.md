# ダウンロード
![VisualStudio](https://storage.googleapis.com/zenn-user-upload/5e1fa8d1a29c-20230927.png)
[Visual Studio Community](https://visualstudio.microsoft.com/ja/vs/community/)
Visual Studio Communityのサイトに行き、「ダウンロード」を押してください。
Visual Studioには複数のバージョンが用意されていますが、無料で十分なので今回はCommunityバージョンを使います。
# インストール
今ダウンロードしたファイルを開いて「続行」します。
するとインストールが始まり、それが終了すると「Visual Studio Installer」というウィンドウが立ち上がります。「インストール済み」にはまだ何もないので「使用可能」というタブに移動してVisual Studio Communityの「インストール」を押してください。他のバージョンは有料なので気を付けてください。
![VisualStudioSetup](https://storage.googleapis.com/zenn-user-upload/4e53db10f8ba-20230929.png)
今回使うのは.NETなので「.NETとデスクトップ開発」にチェックを入れて「インストールを押してください。少し時間がかかります。
# セットアップ
アカウントにログインするか聞かれますが必要ありません。ログインしたい人だけログインしてください。配色テーマは完全に好みの問題なので好きなのを選んでください。わからなければそのままでいいと思います。「Visual Studioの開始」を押せばセットアップが始まります。
# プロジェクト
VisualStudioが開いたら、右下の項目の「新しいプロジェクトの作成」を選んでください。
