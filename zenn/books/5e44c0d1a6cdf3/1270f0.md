# 操作説明
最初の最初は下の表を見ながら操作してみてください。
| 操作 | 動作 |
| - | - |
| 選択 | 上下 |
| 決定 | 中央 |
| 戻る | 左上 |
| 入力 | 上下左右 |
| 強制終了 | 左上+中央 長押し |

ボタンの数が6個しかないので、わからないときはすべて押してみて探ってください。

# サンプルプログラムを動かす
MonoBrickにはサンプルプログラムがいくつか用意されています。
「Programs」を選択すると、プログラムがリストになっています。
例として「MenuExample」を選択して、「Run program」を押すと実行されます。
EV3の画面でサンプルのメニュー表示がされると思います。

他のサンプルもプログラム名から予想がつく思うので、センサーを接続しつついろいろ実行してみてください。
# 機能紹介
:::details Programs
サンプルプログラムと自分で書いたプログラムが置かれる場所です。
様々なプログラムを実行してみましょう。
:::
:::details WiFi Connection
Wifiの設定ができます。接続方法は後ほど説明します。
:::
:::details Settings
設定ができますが、設定項目が少ないのであまり触ることはないと思います。
:::
:::details Information
MonoBrickのバージョンが書いてあります。
ここでIPアドレスの確認ができます。
:::
:::details Check for Updates
Wifiに接続している場合に限り、アップデートが確認できます。
もう更新されていないOSなので、アップデートは永遠とこないと思います。
:::
:::details Shutdown
シャットダウンできます。
:::
# 注意事項
実行されているプログラムを強制終了する手段がありません。
各プログラムの中に停止用のコードがないとプログラムが終了できないのです。
プログラムが停止できなくなったときは左上+中央を長押ししてOS自体を強制終了ください。
