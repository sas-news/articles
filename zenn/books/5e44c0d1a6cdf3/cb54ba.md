# MicroSDカード
OSを動かすうえで絶対に必要なので買っておきましょう。安いもので構いませんが最低4GBはあるといいです。おすすめは安心のTOSHIBA製です。
https://amzn.asia/d/ao0DcpK
PCにMicroSDスロットがない場合はカードリーダーも購入してください。
これを買い忘れるとMicroSDがあっても泣き寝入りすることになります。
![テープ付きMicroSD](https://storage.googleapis.com/zenn-user-upload/b7f694f24315-20230911.jpg)
SDカードを購入したらEV3から取り出しやすいようにテープを付けてください。
テープを付けないと爪が欠けます。取り出せなくなるようなことはありませんが、時々取り外すことになるので付けておくことをお勧めします。
テープの種類ですが、セロハンテープは劣化するので剝がしやすいマスキングテープがおすすめです。
# 7-Zip
この先何回か使用するので入れましょう。今後ほかのことにも使うと思います。
![7-Zip](https://storage.googleapis.com/zenn-user-upload/44274779c7ad-20230911.png)
[7-Zip](https://www.7-zip.org)
サイトにアクセスして一番上の「64-bit x64」の左の「Download」をクリックします。
こだわりがなければ、「Install」を押してそのボタンが「Close」になるまで待ってください。
すぐに「Close」が押せるようになるので押してください。
これで7-Zipのインストールは完了です。
# balenaEtcher
SDカードを焼くためのソフトが必要なので、今回はbalenaEtcherを入れます。
既に何かしらのソフトあればそれを使用しても構いません。
![balenaEtcher](https://storage.googleapis.com/zenn-user-upload/855789d388a5-20230925.png)
[balenaEtcher](https://etcher.balena.io/#download-etcher)
このサイトで「ETCHER FOR WINDOWS (X86|X64) (INSTALLER)」を選んでダウンロードしてください。
ダウンロードしたインストーラーを実行してください。
最初に表示される画面の「同意する」を押せば、インストールされます。
